# Khushi Gajjar — Portfolio Website

A responsive, recruiter-focused portfolio built with plain HTML, CSS, and JavaScript. No build step or paid theme is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Before publishing — personalise these items
Open `index.html` and update:
- `YOUR_EMAIL@example.com` with your professional email.
- The LinkedIn link (`https://www.linkedin.com/`) with your profile URL.
- The GitHub link (`https://github.com/`) with your profile URL.
- The Hugging Face Space link with your actual IssyGPT demo URL.
- Any project links and project descriptions you want to change.
- Check dates, metrics, and all skills for accuracy.

The current text is a starting draft based on information supplied in conversation. Review it carefully before sharing with recruiters.

## Free publishing options

### Vercel
1. Create/sign in to a GitHub account and make a new repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository.
3. Go to https://vercel.com/ and import the repository.
4. Deploy. Vercel will provide a free `*.vercel.app` address, subject to availability and plan terms.

### GitHub Pages
1. Create a public repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In repository Settings → Pages, enable publishing from the `main` branch and root folder.
4. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io`.

## Notes
- Hosting is static; there is no server or database.
- The Google Fonts import requires an internet connection; fallback fonts are included.
- You do not need to buy a custom `.me` domain to publish this site for free.
